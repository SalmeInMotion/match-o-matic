# Match-o-matic

Match-o-matic is a Houdini camera-tracking and reconstruction toolkit by
SalmeInMotion.

This public repository is the official home for:

- beta downloads and release notes;
- public bug reports;
- installation and support documentation.

The product source code is not published in this repository.

## Report a bug

Use the [bug report form](https://github.com/SalmeInMotion/match-o-matic/issues/new?template=bug_report.yml)
or email `bugs@salmeinmotion.com`.

Before posting publicly, remove client footage, confidential project names,
private file paths, licence tokens and any other material you cannot share.
For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.

## Releases

Official beta packages will appear on the
[Releases page](https://github.com/SalmeInMotion/match-o-matic/releases).
Each package will include a SHA-256 digest. Match-o-matic checks release
metadata only; installation always remains an explicit user action performed
with Houdini closed.
