# Security policy

Do not open a public issue for a security vulnerability or include licence
tokens, email access codes, client footage, private paths or credentials in a
report.

Send a private report to `bugs@salmeinmotion.com` with the subject
`Match-o-matic security report`. Include only the minimum information needed
to reproduce the problem. SalmeInMotion will acknowledge the report and agree
on a safe way to exchange any additional evidence.
